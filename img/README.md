- hero.jpg          — foto principal (vertical, 4:5). Fachada, balcón o la calle desde la ventana
- salon.jpg         — salón (horizontal)
- cocina.jpg
- dormitorio-1.jpg
- dormitorio-2.jpg
- dormitorio-3.jpg
- bano.jpg
- vistas.jpg        — vista desde la ventana o el balcón (horizontal)
