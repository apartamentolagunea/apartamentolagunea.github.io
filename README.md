# Apartamento Lagunea

Web estática del apartamento vacacional en San Cristóbal de La Laguna (Tenerife). Sin dependencias ni build: HTML, CSS y un archivo JS para los idiomas (ES, EN, FR, DE).

## Editar

- Textos en español: `index.html`
- Textos en inglés, francés y alemán: `js/i18n.js` (misma clave que el atributo `data-i18n`)
- Fotos: carpeta `img/`, ver `img/README.md`
- Colores y tipografía: `css/style.css`, variables al principio
