# Apartamento Lagunea

Web estática del apartamento vacacional en San Cristóbal de La Laguna (Tenerife). Sin dependencias ni build: HTML, CSS y un archivo JS para los idiomas (ES, EN, FR, DE).

## Editar

- Textos en español: `index.html`
- Textos en inglés, francés y alemán: `js/i18n.js` (misma clave que el atributo `data-i18n`)
- Fotos: carpeta `img/`, ver `img/README.md`
- Colores y tipografía: `css/style.css`, variables al principio

## Pendiente antes de publicar

- [ ] Fotos en `img/`
- [ ] Número de registro de vivienda vacacional (pie de página, clave `foot.reg`)
- [ ] Confirmar lista de equipamiento (wifi, lavadora, etc.)
- [ ] Ubicación exacta en el mapa (ahora apunta al centro de La Laguna)
- [ ] Enlace a Airbnb/Booking si se quiere mostrar

## Publicar

GitHub Pages desde la rama `main`, carpeta raíz. Dominio propio: añadir un archivo `CNAME` con el dominio.
